2. LLM versus code

LLMCode
Classify; copy exact phrases; pick a query function in Ask. 3. Guardrails

  • Grounding check on LLM explanations; rule-based noise cross-check + hard write block on noise.
  • Exactly one escalate for unconfirmed; rule 10 affected-only; one dealer.notify per dealer per event.
  • Verifier blocks on any failed check; twin dry run; read-back after writes.
  • Failed calls: stop remaining plan, escalate with tool + error, no blind retries.
  • Locked scored baseline handbook_v1 in Policy Studio (publish makes a new profile only).

5. Explainability and human in the loop

  • Per-event summary + reason, with graph path evidence in each trace.
  • Human review inbox stores decisions locally; never sent to the enterprise server.

6. What I would improve

  • Desk follow-ups that also disambiguate shipments when several open ETAs match.
  • Stronger grounding so ungrounded LLM rationales are never shown.
  • Constraint solver for contested plant-day slots.
  • Per-dealer notify templates.
  • Streamed event bus instead of a batch of 15.
